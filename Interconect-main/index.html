Presentación de la Feria

Bienvenidos a la Feria Tecnológica Escolar 2026. Un espacio donde los estudiantes presentan sus ideas, prototipos y desarrollos tecnológicos más innovadores.

El objetivo de este evento es impulsar el aprendizaje práctico, la creatividad y la solución de problemas reales mediante la tecnología y la programación.

Sección de Proyectos

Proyecto A: Brazo Robótico Reciclable

Un proyecto enfocado en la automatización de bajo costo utilizando materiales reciclados y servomotores.

Proyecto B: Asistente Web para la Comunidad

Aplicación web diseñada para conectar estudiantes y facilitar el intercambio de materiales de estudio.

Proyecto C: Sistema de Riego Automatizado

Prototipo de cultivo inteligente controlado por sensores de humedad y código en Python.

  • Ubicación: Auditorio Principal / Gimnasio Escolar
  • Hora: 8:00 AM – 2:00 PM
  • Dirigido a: Estudiantes, profesores y acudientes.
